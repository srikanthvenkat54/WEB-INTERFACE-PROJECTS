Engineering Details

How It's Architected

Multi-application mono-repository design engineered for seamless GitHub Pages static hosting.

⚡

Single Index Orchestrator

The root index.html serves as the primary master showcase portal. It embeds a live device simulator capable of dynamically mounting all 10 apps via iframe sandboxes while preserving isolated execution and CSS scopes.

⚛️

Vite 8 & React 19 Engine

Each React project is built with Vite into self-contained production distributions using relative base paths (base: './'). This ensures zero runtime routing breaks across any GitHub Pages subdirectory or custom domain.

🚀

Instant GitHub Pages Deployment

Production assets reside in structured projects/pro-XX/ directories while preserving original source folders (pro 1 to pro 10). Deploys seamlessly from the main branch with automated GitHub Actions CI/CD.
